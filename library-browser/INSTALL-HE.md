# פלייליסטים חכמים ל־XDJ-AZ

התוסף מיועד ל־XDJ-AZ עם AZ-MODS בגרסה 1.2.3 ומעלה. הקובץ נבנה ונבדק במחשב;
הוא עדיין לא הותקן ולא נבדק על קונטרולר פיזי. נדרשת בדיקה על המכשיר לפני שימוש בסט.

## מה נוסף

במסך הפלייליסטים והגלישה הרגיל מופיע כפתור **SMART PLAYLIST**. לחיצה עליו פותחת
רשימת התאמות חיה לשיר שמתנגן, לפי BPM קרוב וסולם תואם. זהו חלון של התוסף מעל
מסך הגלישה. טעינת השירים עדיין נעשית בדפדפן הרגיל.

שלוש רשימות עם כללים שנשמרים בנפרד: טווח BPM, ז׳אנר, סולם, אורך השיר ואמן
בהתאם לשיר שטעון בדק נבחר. אפשר למיין לפי BPM, שם השיר או האמן.
כל לחיצה על הצגת התוצאות קוראת מחדש את ספריית ה־USB.

הרשימות מופיעות במסך התוסף בלבד. הן לא נוצרות ברשימת הפלייליסטים הרגילה של
rekordbox, ולא ניתן לטעון מהן שיר ישירות לדק. טעינת שירים נעשית בדפדפן הרגיל.

## התקנה

### דרך הקונטרולר

1. לפתוח **Mod Menu → Community Mods → Repositories → Add**.
2. להזין `meow3040/az-smart-playlists`.
3. לפתוח **Browse**, לבחור **Smart Playlists** ולבחור התקנה.
4. לבחור **Reload now** כשלא מתנגן סט.
5. לפתוח **Community Mods → Installed → Smart Playlists**.

לתוסף יש מזהה נפרד, `meow-smart-playlists`, והוא יכול להיות מותקן לצד Library Browser
המקורי. אם הותקנה גרסת הניסיון 1.1.0, הכללים השמורים שלה לא עוברים אוטומטית למזהה החדש.

### התקנה ידנית דרך USB

1. לגבות את תיקיית `MODS` שב־USB אם היא קיימת.
2. לחלץ את `smart-playlists-usb-1.2.0.zip` לשורש ה־USB. החבילה מוסיפה או מעדכנת את
   `MODS/community-mods/meow-smart-playlists/`.
3. בקובץ הקיים `MODS/azmods.cfg`, להוסיף את השורה הבאה, או לעדכן אותה אם כבר קיימת.
   לשמור את יתר ההגדרות בקובץ:

   ```ini
   community-mods.meow-smart-playlists = on
   ```

4. להפעיל את המכשיר עם ה־USB מחובר. לפתוח:
   **Mod Menu → Community Mods → Installed → Smart Playlists**.
5. אם מופיעה בקשת אישור לגרסה החדשה, לבחור **Allow**, ואז **Reload now** כאשר לא מתנגן סט.

קובץ `meow-smart-playlists-1.2.0.azmod` הוא אותה חבילת תוסף בפורמט AZ-MODS.
אפשר לחלץ את תוכנו ישירות לתיקיית `MODS/community-mods/meow-smart-playlists/` במקום שלב 2.
אין צורך להשתמש בשתי החבילות.

## התאמות חיות

1. אחרי עדכון התוסף ובחירת **Reload now**, לפתוח את מסך הפלייליסטים או הגלישה הרגיל.
2. ללחוץ על **SMART PLAYLIST** ליד הפינה הימנית העליונה.
3. כשמתנגן דק אחד, מצב **Reference: Auto** מתייחס אליו. אם מנגנים כמה דקים,
   ללחוץ על **Reference** ולבחור את הדק הרצוי.
4. ללחוץ על **BPM** לבחירת הפרש של 2, 4, 6 או 10 BPM. ברירת המחדל היא 4.
5. **Key: Compatible** מציג סולם זהה, סולם שכן בגלגל Camelot או מז׳ור/מינור מקביל.
   לחיצה מעבירה ל־**Any** לביטול סינון הסולם. כשהסולם של שיר המקור אינו ידוע,
   מוצגת הודעה שההתאמה היא לפי BPM בלבד.
6. לסובב את כפתור הגלילה כדי לראות את ההתאמות. **BACK** או **X** סוגרים את החלון.

הרשימה מתעדכנת לפי השיר והקצב בערך פעם בשנייה. **Rescan USBs** קורא מחדש את
הספריות; סריקה נעשית גם בפתיחה, בהחלפת שיר המקור ובכל 30 שניות כשהחלון פתוח.
כל שורה מציינת מאיזה USB השיר מגיע. במצב החי אפשר לגלול בכל ההתאמות שנמצאו,
עד מגבלת הסריקה של 20,000 שירים בכל USB. חלון זה אינו יוצר פלייליסט שמור ב־USB.

## שימוש בכללים שמורים

1. בתוך התוסף, לגלול אל **Smart Playlists >** שמתחת לפלייליסטים של ה־USB.
2. בשורת **Playlist**, ללחוץ ולסובב כדי לבחור **Smart 1**, **Smart 2** או **Smart 3**.
3. לגלול לתנאי, ללחוץ לעריכה, לסובב לשינוי, ואז ללחוץ שוב לסיום. ההגדרות נשמרות אוטומטית.
4. לבחור **Show matching tracks >** להצגת התוצאות. **BACK** חוזר לעריכת הכללים.

נקודת הפתיחה היא עד 109 BPM ברשימה הראשונה, 120–129 בשנייה, ומ־140 בשלישית.
הגבולות כוללים את המספר שנבחר. ערך 0 מוצג בתור **Any** ומבטל את הגבול.
אפשר לשנות כל תנאי בכל רשימה. הכללים משותפים לשני חיבורי ה־USB; התוצאות נקראות
רק מה־USB שנבחר.

לדוגמה: **BPM minimum: 122**, **BPM maximum: 128**, **Genre: House**, **Key: 8A**.
יופיעו רק שירים שעומדים בכל התנאים יחד.

## ז׳אנרים

ממשק AZ-MODS לא מספק לתוסף את תגית הז׳אנר של השיר. כדי להשתמש בסינון ז׳אנר,
צריך לייצא מ־rekordbox פלייליסטים בשם **Genre: House**, **Genre: Techno** וכדומה.
השיוך לז׳אנר נקבע לפי החברות בפלייליסט הזה. אפשר להכין את רשימת המקור כפלייליסט
חכם ב־rekordbox לפני הייצוא. לכל ז׳אנר צריך להיות שם פלייליסט ייחודי על אותו USB.

בתוצאות מוצגים עד 256 שירים, אחרי הסינון והמיון. כל חיפוש קורא עד 20,000 שירים;
אם הספרייה גדולה יותר, מופיע סימון **scan limited**. שירים שחסרים להם BPM, סולם
או אורך לא ייכללו כאשר מופעל תנאי שמחייב את הנתון החסר.
